⇋ اتصال بدون کلید — Device Flow

ابزارها (Cline، Kilo Code، Hermes، Copilot و هر کلاینت OpenAI/Anthropic) با استاندارد RFC 8628 وصل می‌شوند: کد می‌گیرند، اینجا تأیید می‌کنید و کلید مجازی اختصاصی خودکار ساخته می‌شود.

1curl -X POST localhost:8080/oauth/device/start -d '{"client":"cline"}'
2← user_code ← باز کن /oauth/authorize
3curl -X POST localhost:8080/oauth/device/poll → access_token

✦ Cline

در تنظیمات، API Provider را روی OpenAI Compatible بگذار؛ یا با دستگاه: client:"cline". حالت Anthropic هم با همان کلید روی /v1/messages کار می‌کند.

✦ Kilo Code

پروفایل‌های Architect/Code/Debug هر کدام می‌توانند یک اتصال جدا بگیرند — برای هر پروفایل یک کلید مجازی با سقف مستقل.

✦ GitHub Copilot / Hermes

Copilot به‌عنوان کلاینت روتر (client:"copilot") و Hermes با client:"hermes" — tool-calling کامل مثل 9router.

⇋ Keyless connection — Device Flow

Tools (Cline, Kilo Code, Hermes, Copilot and any OpenAI/Anthropic client) connect over RFC 8628: they request a code, you approve it here, and a dedicated virtual key is minted automatically.

2open /oauth/authorize → approve user_code
3curl -X POST localhost:8080/oauth/device/poll → access_token
